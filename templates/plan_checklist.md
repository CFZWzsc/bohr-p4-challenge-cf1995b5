# 实验方案复核清单

用途：对一份由技能生成、或人工提交的实验方案做结构化复核。逐项勾选，未勾选项写明原因；本清单不替代伦理、安全与设备管理部门的正式审批。

案例编号：__________　方案版本：__________　复核人：__________　复核日期：__________

## 1. 目标与假设

- [ ] 研究目标可定位到输入案例的 `objective` 或 `task` 原文，未被改写为更宽或更窄的问题。
- [ ] 每条假设都写明自变量、因变量、比较方向与可证伪判据。
- [ ] 没有把“预期结果”写成“已获得结果”。

## 2. 变量与操作性定义

- [ ] 每个变量标注角色（自变量/因变量/混杂/控制）。
- [ ] 自变量取值范围来自输入参数域或设备量程，未自行扩边。
- [ ] 因变量的测量方法与单位明确，可被第三方重复。

## 3. 对照与分组

- [ ] 有空白或阴性对照，并说明排除的混杂来源。
- [ ] 有阳性对照，且能证明检测体系本身有效。
- [ ] 有条件梯度或剂量梯度，可区分真实响应与单点伪影。
- [ ] 分组与随机化方式已记录（随机种子、区组变量）。

## 4. 步骤与排期

- [ ] 步骤顺序为“样品准备→分组/对照→处理→测量→判读”，每步有产出物。
- [ ] 每步标注设备、参数区间、时长与前置依赖。
- [ ] 关键步骤采用的方案版本（体积、温度、重复数、时长）与输入一致。
- [ ] 总时长与 `time_window_h` 核对，冲突项已标注而非静默压缩。

## 5. 资源与预算

- [ ] 耗材按“数量 × 单价”列出，行成本可复算。
- [ ] 设备按机时与费率计费，费率来源可追溯。
- [ ] 总成本与 `budget_limit` 比较，差额与超支项写明。
- [ ] 未标价资源单独列出，未被估造价格。

## 6. 重复与统计

- [ ] 生物学重复数与技术重复数分别写明。
- [ ] 重复数不低于案例明示的 `min_replicates`。
- [ ] 样本量限制与统计功效的未决项已标注给统计人员。

## 7. 风险与异常

- [ ] 覆盖污染/携带、无信号或饱和、重复性差、样本不足、设备排期冲突。
- [ ] 每条风险有触发条件、止损点与替代路径。
- [ ] 有明确的转人工升级节点。

## 8. 待确认项

- [ ] 安全与危废处置已提交本地确认。
- [ ] 伦理或动物/人体样本审批状态已核实（触发时）。
- [ ] 设备可用性与预约窗口已由设施管理方确认。
- [ ] 供应商报价与交货期已由采购确认。

## 9. 交付完整性

- [ ] `plan`、`steps`、`risks`、`budget` 在同一份输出中齐全。
- [ ] `status` 与实际情况一致（存在未决项时不得标为 `success`）。
- [ ] `uncertainty` 的每条说明都有对应处理人或后续动作。
