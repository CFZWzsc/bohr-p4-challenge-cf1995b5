# 实验方案基准报告

协议版本：`plan-bench-v1`。本报告由 `bench/run_bench.py` 生成，内容只依赖案例、金标准与两次运行输出。

## 公平协议

- 案例：`bench/cases/*.json`，合成且自洽；金标准：`bench/gold/*.json`，只取案例中明示的约束。
- 两侧使用同一条成本规则：耗材按目录 `quantity*unit_price`，设备按方案 `duration_h*unit_price`（单价为每小时费率）。
- 技能侧：运行 `scripts/run_skill.py`，从其输出中恢复所选方案版本、重复数与时长；约束判定只比较数值与计数，不做人工解释。
- 基线：直接采用案例中的第 1 版方案（未核算预算与排期的默认方案），不生成对照、风险与预算核对。
- 判定：预算 `cost <= budget_limit`、时间 `duration_h <= time_window_h`、重复 `replicates >= min_replicates`、
  对照/风险 `controls >= 3 且 risks >= 4`（协议级要求，非案例约束；技能在 SKILL.md 中承诺，基线不提供）。
- 每个案例独立运行一次，运行目录为临时目录并在结束后删除；不使用网络、不使用随机数。

## 指标定义

- 约束满足数：上述 4 条约束中通过的条数；未满足约束数为 4 减去满足数。
- 单次运行交付：一次运行是否同时产出 `plan`、`steps`、`risks`、`budget`（且 `budget.total_cost` 非空）。
- 成本、时长、重复数均按该方案自身声明的字段计算，两侧规则完全一致。
